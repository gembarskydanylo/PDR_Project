# Оновлені файли PDR_Project

Архів містить лише змінені файли, зі збереженою структурою папок. Його вміст підготовлено відносно `main` на момент роботи.

## Як завантажити через GitHub

1. Завантажте й розпакуйте `PDR_Project-changes.zip`.
2. У GitHub відкрийте репозиторій `gembarskydanylo/PDR_Project` і перейдіть на гілку, куди потрібно внести зміни.
3. Відкрийте файли з архіву за відповідними шляхами та замініть їх вміст на GitHub. Для кожного файлу створіть або оновіть файл за тим самим шляхом.
4. Створіть commit. Щоб зміни потрапили на сайт, їх треба внести в `main` або змерджити гілку в `main`.

Змінено дорожні знаки та пов'язані навчальні дані, додано теми «Навчальна» і «Енергійна», адаптивну навігацію та оновлено кеш застосунку.
