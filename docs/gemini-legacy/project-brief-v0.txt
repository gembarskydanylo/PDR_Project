Я розробляю мобільний навчальний PWA-застосунок «ПДР Бельгії» для українців, які готуються до теоретичного іспиту на категорію B. Інтерфейс підтримує чотири мови: українську (uk), нідерландську (nl), французьку (fr) та англійську (en). Увесь проєкт побудований на чистому HTML, CSS та JavaScript (ES6+) без зайвих фреймворків, із локальним збереженням прогресу (localStorage).

Ось поточна структурована кодова база та дані проєкту, якими ми користуємося:
