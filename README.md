# ПДР Бельгії — Belgian Driving Theory App

Навчальний PWA-застосунок для підготовки до теоретичного іспиту на категорію B у Бельгії.

## Мови
- 🇺🇦 Українська
- 🇳🇱 Nederlands
- 🇫🇷 Français
- 🇬🇧 English

## Поточний стан (Етап 1 — основа)

✅ Головний екран з прогресом  
✅ Перемикання 4 мов  
✅ Меню з 12 темами  
✅ Нижня навігація  
✅ Локальне збереження прогресу (localStorage)  
✅ Service Worker для офлайн-режиму  
✅ PWA-маніфест  

🔜 Наступні кроки:
- База питань і знаків
- Візуальні завдання
- Режим іспиту (50 питань)
- Повторення помилок

## Як запустити

1. Відкрий `index.html` у браузері (або через локальний сервер).
2. Для повноцінного PWA і офлайн краще використовувати локальний сервер:

```bash
# З папки belgium-driving-app
npx serve .
# або
python3 -m http.server 8080
```

Потім відкрий http://localhost:8080

## Примітка щодо правил

Усі навчальні матеріали мають базуватися на офіційних бельгійських джерелах. Перед публікацією питань обов'язкова перевірка актуальності (особливо через перехідний період нового Кодексу громадського руху).
